How to get a file set

Run the exporter in the repo against your own borrower list. It writes one folder of csv files, which is what this page reads:

python -m src.export_powerbi \
    --borrowers path/to/your_borrowers.csv \
    --out path/to/export \
    --data-label UPLOADED

The engine computes every number. This page only adds up and ranks what the engine wrote, so a figure you see here is a figure the engine produced.
